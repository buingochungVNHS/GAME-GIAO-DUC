# Game Giáo Dục

Game luyện nói và từ vựng tiếng Anh giao tiếp, dùng cá nhân. Mở bằng trình duyệt (Safari trên iPhone, Chrome trên Android):
https://buingochungvnhs.github.io/GAME-GIAO-DUC/

- `index.html`, `css/`, `js/`: ứng dụng (bản 1)
- `test.html`: trang thử âm thanh và micro (chẩn đoán)
- Tiến độ lưu trên máy người dùng, không có dữ liệu cá nhân trong kho này.
